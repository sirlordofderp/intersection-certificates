# Reusable witnesses for extensions of a matched affine formula

Fix r binary coordinates. Matched clause i contains the baseline option xᵢ=bᵢ and any number of additional parity equations. Suppose a later query can append up to k affine clauses. Can one prepare a short list of actual models that answers *every* such future query?

**Result.** Set D(r,k)=Σⱼ₌₀ᵐⁱⁿ⁽ʳ˒ᵏ⁾ binom(r,j). There is a deterministic construction of a list of at most D(r,k) models with this property. Given a fixed pivot order, let h be the minimum dimension of a space of globally guessed parities that makes the construction below triangular. Its time is bounded by 2ʰ times a polynomial in the explicit input length and D(r,k+h). Its space is polynomial in those latter two quantities. Thus fixed k+h gives deterministic polynomial time. For each fixed positive k, some triangular inputs already require Ωₖ(rᵏ) actual models for this reusable-list task.

## Minimum feedback for a fixed order

Let Pᵢ be the span of the first i coordinate normals, including the pivot for the current clause. Seek a subspace H such that every normal of clause i belongs to Pᵢ+H. Scan the clauses in order. Insert the current coordinate into an elimination basis, then insert the clause normals. Record a normal in a list exactly when it increases the running rank. Here only rank increases caused by clause normals enter the list. The list spans a feasible H.

For optimality, write the recorded normals in order as v₁,…,vₕ, and let P(j) denote the prefix at recording time. By construction vⱼ lies outside P(j)+span(v₁,…,vⱼ₋₁). In any feasible H′ choose wⱼ in H′ with wⱼ−vⱼ in P(j). In any dependence among the wⱼ, take the last index with nonzero coefficient. All previous discrepancies belong to its prefix. The dependence would express that last vⱼ using the prefix and earlier recorded normals, a contradiction. Thus h independent vectors are required. The optimization is for a **specified basis and ordering**. This is a triangular partial-matrix minimum-rank completion problem. [Woerdeman, 1989](https://doi.org/10.1016/0024-3795(89)90695-2)

## Affine transitions and compression

Guess the h parity values, and process each pivot once. Every option now depends only on the prefix and the current pivot. An option involving the pivot specifies an affine value for it. A pivot-free option with truth bit u permits either value when u=1. The baseline permits bᵢ, so adding the unconditional affine update xᵢ=bᵢ+u supplies precisely the additional choice. An inconsistent initial guess is discarded by checking all h guessed equations at the end. On consistent guesses the reachable states are exactly the matched models with those parity values.

For a degree budget d, lift a binary point to the vector of values of all squarefree monomials of degree at most d, including 1. Binary elimination on these vectors retains at most D(r,d) *actual points*. Every polynomial of degree at most d that is nonzero on a discarded point is nonzero on a retained point. Substitution by an affine transition preserves the degree bound, and repeated variables reduce using x²=x. Taking the union over all transition choices and pruning again therefore preserves this property at every layer. The argument is related to computation of bounded-degree invariants of nondeterministic affine programs. [Müller-Olm and Seidl](https://www.uni-muenster.de/imperia/md/content/informatik/agmueller-olm/publications/icalp04.pdf)

If a future query has a satisfying point, select one true equation from each of its at most k clauses. Multiply their truth bits and those of the h guess checks. This is a polynomial of degree at most k+h, taking value one at the point. Consequently some retained point passes both the query and the checks. Filter by the checks, join the surviving lists across guesses, and prune at degree k. Every point in the resulting list satisfies the matched formula, and every satisfiable query has an actual witness on the list. Queries need only scan this final list. The implementation streams the guesses and their final survivors. At each layer it generates at most the number of options times D(r,k+h) candidate points. All masks, elimination tables, and feature vectors have explicit polynomial bit size in the stated parameters.

For a dense example, give each coordinate the alternatives xᵢ=0 and Σⱼxⱼ=1. A single guessed parity suffices for the entire formula, even though each pivot has dependencies on all other coordinates. The matched family consists of zero and all odd-weight vectors. In 24 coordinates the algorithm kept 25 actual assignments for any one subsequent affine clause.

## A lower bound on reusable lists

Take k blocks of b variables each. Within a block give position j the clause

$$ (x_j=0)\quad\lor\quad\left(x_j+\sum_{i<j}x_i=1\right). $$

These clauses are triangular. Before the first occupied position the next bit is free. After a one, all subsequent bits must be zero. Each block therefore has exactly b+1 feasible patterns. For any prescribed model, add one equation per block. If a position is occupied, require its bit to be one. For an empty block, require the whole block's parity to be zero. These k equations isolate exactly the prescribed model. Every reusable list must consequently contain **all (b+1)ᵏ models**, with r=kb. The exponent of r in the list-size bound is sharp for fixed k. A decision algorithm specialized to a single query need not output such a list.

## Reproduction and scope

The deterministic entry point `ordered_affine.solve` accepts arbitrary affine clauses. It obtains matched coordinates by transversal augmentation and lifts any core witness to physical coordinates by elimination. Without a degree cutoff its answer is exact and its worst-case running time can be exponential. Supplying `max_degree` gives the explicit status `DEGREE_LIMIT` when the requested budget is exceeded. For several future queries on the same matched system, use `representative_models` directly. The principal graph result handles reciprocal cases where h grows with the input. Lean checks affine successor preservation, guess closure, preservation of affine-clause queries, feature pruning, the pivot-free update, and the isolation/counting argument on the block encoding. ## Randomized comparison

The separate `affine_shortfall.solve` reproduces the matched-core polynomial witness criterion independently and supplies a simpler, slower evaluator at fixed deficiency k. Give each occurrence its own weight. Sum over the Boolean cube the product of one weighted affine truth form per core clause. Each satisfying point can be isolated: in every matched clause use a true option, or the sum of that option and a false baseline. A row-at-a-time determinant exchange preserves an invertible set of slopes. The extra clauses each supply a true option. The product now isolates the chosen point, so the formal moment is nonzero. Conversely an unsatisfiable formula gives the zero polynomial. Lean checks the mixed-option characterization in `sat_iff_nonzero_moment`. The earlier preprint establishes this criterion and a stronger randomized 2ᵏ poly(L) algorithm. We claim no priority for it. [OpenAI Codex and Yichuan Wang](https://airaxiv.com/papers/pdf/2611.0031/?v=1) · [Lean source](AffineShortfall.lean)

For our evaluator there are r+k rows and r coordinates. In characteristic two only products using every coordinate survive summation over the Boolean cube. Mark the k rows using a constant or a repeated coordinate after its first occurrence. For each choice of marked positions and labels, the unmarked rows form a permutation of the r coordinates. Zero out entries whose putative first occurrence follows a marked repeat. The permutation sum is a determinant. At most binom(r+k,k)(r+1)ᵏ determinants suffice. For k=1 the implementation shares cofactor calculations across deleted columns by solving rectangular nullspace systems. Every step uses polynomial space for fixed k. Independent occurrence weights in a binary extension field of size at least 4(r+k) give at most a 1/4 miss probability per trial by the polynomial identity bound. A nonzero evaluation can be specialized one row at a time to return a checked witness. `NO_HIT` is inconclusive. The fixed-k comparison suite checked the coefficient criterion on all 10,422 one-shortfall instances in a two-coordinate family, and checked 640 field evaluations by summing directly over points.
